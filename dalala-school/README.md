# منظومة دلالة للمدارس — Dalala School System

منظومة حديثة متكاملة لإدارة المدارس من **المرحلة الابتدائية حتى الثانوية** (الصف الأول – الثالث الثانوي)، بواجهة عصرية تدعم **العربية والإنجليزية** (RTL / LTR) والوضع الليلي، وتعمل على الحاسوب والجوال.

A modern, bilingual (Arabic / English) school management system covering Grade 1 through Grade 12.

## التشغيل — Getting started

لا يحتاج النظام إلى أي تثبيت أو خادم قاعدة بيانات: افتح `index.html` في المتصفح، أو شغّل خادماً محلياً:

```bash
cd dalala-school
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## التثبيت على ويندوز — Windows installer

1. شغّل الملف `Dalala-School-Setup-1.1.0.exe` واختر لغة المثبّت (العربية / English).
2. اختر مجلد التثبيت (الافتراضي داخل مجلد المستخدم — **لا يحتاج صلاحيات المدير**).
3. يُنشئ المثبّت اختصاراً على سطح المكتب وفي قائمة ابدأ باسم «منظومة دلالة للمدارس»، ويظهر في «إضافة/إزالة البرامج».

- يعمل البرنامج **بدون إنترنت** بالكامل (الخطوط مضمّنة).
- تُحفظ البيانات في `%APPDATA%\Dalala School System` ولا تُحذف عند إلغاء التثبيت أو الترقية.
- يدعم Windows 10 و 11 (64-بت).
- قد يظهر تحذير «Windows protected your PC» لأن الملف غير موقّع رقمياً: اضغط **More info ← Run anyway**.

### بناء المثبّت — Building the installer

```bash
cd dalala-school/desktop
npm install
npm run dist          # على Linux/macOS بدون Wine → dist/Dalala-School-Setup-<version>.exe
npm run dist:builder  # على ويندوز مباشرة عبر electron-builder
npm start             # تشغيل نسخة سطح المكتب للتجربة
```

كما يبني ملف GitHub Actions ‏`.github/workflows/build-dalala-windows.yml` المثبّت تلقائياً على ويندوز عند أي تعديل في `dalala-school/`، ويرفعه كـ Artifact.

## التوافق مع النظام التعليمي الليبي — Libya

الإعداد الافتراضي هو **دولة ليبيا** (يمكن تغييره من الإعدادات → الجهة التعليمية):

| البند | التطبيق في المنظومة |
|---|---|
| المراحل | التعليم الأساسي (الابتدائي 1–6 والإعدادي 7–9) والتعليم الثانوي (10–12) |
| الأقسام الثانوية | القسم العلمي / الأدبي / الديني، ولكل قسم مواده (فيزياء، كيمياء، أحياء / تاريخ، جغرافيا، فلسفة، علم اجتماع) |
| المواد | القرآن الكريم، التربية الإسلامية، اللغة العربية، الإنجليزية، الرياضيات، العلوم، الدراسات الاجتماعية، التربية الوطنية، الحاسوب… |
| التقويم | فصلان دراسيان: أعمال الفصل (40) + امتحان الفصل (60)، ونتيجة سنوية بمتوسط الفصلين |
| التقديرات | ممتاز ≥ 85، جيد جداً ≥ 75، جيد ≥ 65، مقبول ≥ 50، ضعيف أقل من 50 |
| النتيجة | ناجح / **دور ثانٍ** (حتى عدد مواد قابل للضبط) / راسب، مع ذكر مواد الدور الثاني في الشهادة |
| الغياب | نسبة إنذار ونسبة حرمان قابلتان للضبط، وتنبيهات في ملف الطالب وتقرير خاص بالمنذرين |
| بيانات الطالب | الاسم الرباعي، اسم الأم، الرقم الوطني (12 رقماً مع التحقق من الجنس وسنة الميلاد)، مكان الميلاد، الجنسية، رقم قيد العائلة، رقم الجلوس |
| الهاتف | التحقق من أرقام ليبيا (091/092/094/095 أو ‎+218) |
| الشهادات العامة | كشوف مترشحي **شهادة إتمام التعليم الأساسي** (الصف 9) و**الثانوي** (الصف 12) مع تدقيق اكتمال البيانات وتوليد أرقام الجلوس وتصدير وطباعة الكشف |
| الشهادة المطبوعة | ترويسة «دولة ليبيا — وزارة التربية والتعليم — مراقبة التربية والتعليم» واسم البلدية والرقم الوزاري للمدرسة |
| أخرى | العملة الدينار الليبي (د.ل)، الدوام من الأحد إلى الخميس، قائمة البلديات الليبية، العطل الرسمية في التقويم |

> **مهم:** النسب الافتراضية (حدود التقديرات، عدد مواد الدور الثاني، نسب الغياب) مبنية على الممارسة الشائعة، ويجب مطابقتها مع **لائحة تنظيم شؤون التربية والتعليم (قرار مجلس الوزراء رقم 1013 لسنة 2022)** وتعليمات الوزارة السارية، وجميعها قابلة للتعديل من صفحة الإعدادات.

## الوحدات — Modules

| المجال | الوحدات |
|---|---|
| **شؤون الطلاب** | سجل الطلاب، ملف الطالب الشامل، القبول والتسجيل (مع تحويل المقبول إلى طالب بضغطة)، الحضور والغياب اليومي (حاضر / غائب / متأخر / بعذر)، السلوك والانضباط |
| **الشؤون الأكاديمية** | الشهادات العامة (9 و12)، الصفوف والشعب حسب المراحل الثلاث، المواد ونطاق صفوفها، الجدول الدراسي مع منع تعارض المعلمين، الاختبارات، رصد الدرجات، النتائج والترتيب، طباعة الشهادات، الواجبات |
| **الموارد البشرية** | المعلمون والموظفون بأدوارهم (معلم، مدير، وكيل، محاسب، مرشد، سائق…) ونصاب المعلم الأسبوعي |
| **الشؤون المالية** | أنواع الرسوم حسب المرحلة، الفواتير مع الخصومات، إصدار فواتير جماعية، المدفوعات مع منع الدفع الزائد، طباعة الفواتير وسندات القبض |
| **الخدمات** | المكتبة (الكتب والنسخ المتاحة)، الإعارات والمتأخرات، النقل المدرسي (الحافلات وخطوط السير والركاب) |
| **التواصل** | الإعلانات الموجهة (للكل / الموظفين / أولياء الأمور / الطلاب)، التقويم المدرسي الشهري |
| **مراسلة أولياء الأمور (واتساب)** | دعوة لاجتماع أولياء الأمور، استدعاء ولي أمر، نتائج الامتحانات لكل طالب، إشعار الغياب والتأخر، تذكير بالرسوم، ورسالة مخصصة — برسائل جاهزة قابلة للتعديل، وإرسال متتابع لكل المستلمين، وسجل للرسائل. يعمل عبر روابط واتساب المجانية (wa.me) دون حساب WhatsApp Business API |
| **بوابة ولي الأمر** | متابعة كل الأبناء: الحضور، الدرجات، الجدول، الواجبات، الرسوم، السلوك |
| **التقارير** | لوحة مؤشرات، توزيع الطلاب، نسب الحضور، توزيع التقديرات، متوسطات المواد، التحصيل المالي، الطلاب المتعثرون، تصدير CSV (يُفتح في Excel) |
| **النظام** | المستخدمون والصلاحيات حسب الدور، الإعدادات (بيانات المدرسة، العام الدراسي، العملة، أيام الدوام، الحصص)، النسخ الاحتياطي والاستعادة |

### الصلاحيات — Roles

- **مدير النظام**: كامل الصلاحيات.
- **المعلم**: الحضور، رصد الدرجات، الواجبات، السلوك، الجداول، النتائج.
- **المحاسب**: الفواتير، المدفوعات، أنواع الرسوم، التقارير.
- **أمين المكتبة**: الكتب والإعارات.
- **ولي الأمر**: بوابة الأبناء، الإعلانات، التقويم.

## التقنية — Tech

- HTML + CSS + JavaScript بدون أطر عمل أو خطوة بناء (لا يحتاج `npm`).
- تُحفظ البيانات في `localStorage` على المتصفح؛ استخدم **النسخ الاحتياطي** (JSON) لنقل البيانات بين الأجهزة.
- خط Cairo مضمّن محلياً (رخصة SIL OFL) فيعمل بدون إنترنت.
- نسخة سطح المكتب: Electron + مثبّت NSIS (مجلد `desktop/`).

```
dalala-school/
├── index.html
├── assets/logo.svg
├── css/style.css      # التصميم، RTL/LTR، الوضع الليلي، الجوال، الطباعة
└── js/
    ├── i18n.js        # الترجمة عربي / إنجليزي
    ├── core.js        # أدوات مساعدة، أيقونات، رسوم بيانية، نوافذ
    ├── store.js       # التخزين والبيانات التجريبية
    ├── entities.js    # تعريف الكيانات ومحرك الإضافة والتعديل والحذف
    ├── pages.js       # الصفحات المخصصة (لوحة التحكم، الحضور، الدرجات…)
    └── app.js         # التنقل، تسجيل الدخول، الأحداث
```

> **ملاحظة:** هذا الإصدار يعمل بالكامل داخل المتصفح، وهو مناسب للعرض والتجربة واستخدام جهاز واحد. كلمات المرور تُخزَّن محلياً دون تشفير. للاستخدام الفعلي متعدد المستخدمين يُنصح بربط النظام بخادم وقاعدة بيانات مركزية مع تشفير كلمات المرور.
